# Keshav Mishra

CSE student building full-stack systems, compilers, and algorithm-driven projects — with a focus on real-time backend architecture.

## Selected Projects

**[PatchLoop](https://github.com/keshavm21/patchloop)**
Self-repairing coding agent that patches buggy Python from test feedback inside a two-container Docker sandbox, with a mutation-based benchmark and a chaos suite for the sandbox.
`Python` `Docker` `pytest` `GitHub Actions`

**[Relay](https://github.com/keshavm21/chat-app)**
Real-time chat app with public and private channels, DMs, and unread counts. It uses cookie-based sessions with CSRF checks and rate limiting, and numbers messages in order per conversation in PostgreSQL. Integration-tested against a real database.
`React` `Node.js` `Express` `Socket.io` `PostgreSQL`

**[Chess Engine AI](https://github.com/keshavm21/Chess-Engine-AI)**
Chess engine in Python with perft-verified move generation and an iterative-deepening negamax search (alpha-beta, quiescence, transposition table). It plays through a Pygame GUI or any UCI chess GUI, and search changes are validated by a tactics suite and self-play matches.
`Python` `Pygame` `UCI` `pytest`


**[Mini C Compiler](https://github.com/keshavm21/Mini-C-Compiler)**
Lexer, parser, and intermediate code generator for a subset of C, producing three-address code as an intermediate representation.
`C` `Lex` `Yacc`

**[Kite](https://github.com/keshavm21/kite)**
Optimizing compiler in C++17 for a small GPU kernel language, targeting NVIDIA PTX. SSA-based optimizer (GVN, LICM, loop unrolling), validated against an interpreter oracle and a fuzzer, and run on a Tesla T4.
`C++` `PTX` `CUDA` `SSA`

**[PR Investigator](https://github.com/keshavm21/pr-investigator)**
Evidence-driven AI reviewer for GitHub pull requests. It investigates hypotheses with read-only repository tools and reports a finding only if every cited line was returned by a tool, checked against the analyzed commit. A human approves what gets posted, and each component is evaluated by ablation on a held-out split with bootstrap intervals.
`Python` `SQLite` `tree-sitter` `GitHub App`
